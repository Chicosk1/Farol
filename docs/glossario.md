# Glossário

Termos usados nas especificações, no código e nas telas. Quando um termo aparece numa spec, ele tem exatamente este sentido.

| Termo | Significado |
| --- | --- |
| Aula | Unidade de organização do material de uma disciplina (Aula 1, Aula 2...). Cada material pertence a uma aula. |
| Citação | Referência ao trecho de onde veio uma afirmação, no formato "Aula N, p. M" ou "Aula N, slide M". Abre o material na página certa, com o trecho destacado. |
| Disciplina | Uma disciplina ofertada para uma turma em um semestre, com um professor responsável. |
| Dúvida ao professor | Pergunta que o tutor não respondeu e que o aluno escolheu enviar ao professor. Chega sem identificação do aluno. |
| Janela de prova | Período agendado pelo professor em que o tutor fica indisponível na disciplina. |
| Limite diário | Número máximo de perguntas que um aluno pode fazer ao tutor por dia, por disciplina. Padrão: 40. |
| Material | Arquivo PDF publicado pelo professor em uma aula. Só material com status "pronto" alimenta o tutor e o gerador de questões. |
| Modo pistas | Configuração da disciplina em que, diante de um pedido de resposta de exercício, o tutor guia por perguntas e dicas em etapas em vez de entregar o resultado. |
| Modo prova | Configuração da disciplina que pausa o tutor para toda a turma, de imediato ou numa janela de prova agendada. |
| Política de uso de IA | Texto escrito pelo professor que diz como a turma pode usar o tutor. Aparece para o aluno no tutor. |
| Quiz | Conjunto de questões aprovadas de uma aula, que o aluno responde com retorno imediato. |
| Radar da turma | Painel do professor com os tópicos de mais dúvida, a taxa de acerto e as dúvidas sem resposta, sempre de forma anônima e agregada. |
| Rascunho | Questão gerada pela IA que ainda não foi aprovada pelo professor. Rascunhos nunca aparecem para o aluno. |
| Revisão do dia | Sessão curta (até 10 cartões, cerca de 5 minutos) com questões aprovadas agendadas por repetição espaçada. |
| Repetição espaçada | Técnica que reapresenta uma questão em intervalos crescentes, mais curtos quando o aluno teve dificuldade. |
| Tópico | Grupo de perguntas parecidas, com um nome curto (por exemplo, "Recursão"). Só aparece no radar se vier de pelo menos 5 alunos diferentes. |
| Trecho | Pedaço do texto de um material (cerca de 500 tokens), com aula, arquivo e página de origem. É a unidade de busca do tutor. |
| Tutor | Assistente de estudo de uma disciplina que responde só com base nos materiais prontos dela, sempre com citação. |
